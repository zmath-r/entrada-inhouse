# Pasta de Registros, Mudanças e Auditoria do Sistema
**Entrada InHouse • Controle de Acesso Inteligente**

Esta pasta foi criada como repositório central de documentação e rastreamento para auditorias técnicas, legais e operacionais do projeto.

---

## Conteúdo da Pasta

1. **`HISTORICO_MUDANCAS.md`**  
   - Registro cronológico de todas as releases, melhorias de arquitetura, correções de bugs e novas funcionalidades implementadas no software e firmware.

2. **`AUDITORIA_E_LOGS.md`**  
   - Detalhamento técnico do modelo de dados de logs (`access_logs`), classificação dos eventos (`ENTRY`, `DENIED`, `EMERGENCY`), conformidade jurídica com a LGPD e parâmetros de exportação de dados.

---

> **Nota:** Mantenha os arquivos desta pasta atualizados a cada novo ciclo de entrega ou alteração no modelo de dados e regras de negócio de acesso.
